# Forest Fires by State 1992–2015

Data preparation and trend analysis of U.S. wildfire data across all 
50 states over 23 years. Fire counts, acres burned, and burn duration 
are aggregated by decade to surface long-term structural trends relevant 
to disaster planning and resource allocation.

---

## Key Findings

Decade-level aggregation reveals regional fire burden patterns not 
visible in annual snapshots. Western states account for 
disproportionate acreage burned per decade, while fire counts and 
average burn duration show regional variation that annual figures 
tend to obscure.

---

## Analysis Includes

- Decade-averaged fire counts, acres burned, and days burning by state
- Lambda expressions for column derivation and type conversion
- Multi-index construction and unstacking for state × decade comparison
- Pivot tables and bin segmentation for magnitude classification
- Index normalization and data combination pipeline
